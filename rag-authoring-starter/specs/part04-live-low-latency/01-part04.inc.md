# Scope # {#scope}


This document specifies interoperability points for **live and low-latency live
DASH services** as part of DASH-IF IOP v5 Part 4.

Note: This is a working-draft skeleton created in the IOPv5 authoring workspace.
Prose is migrated and reconciled from the sources tracked in
`rag/sources.yaml` (the Part 4 draft, Low-Latency CR r8/r9, and the relevant
MPEG DASH / CMAF baselines).

# Normative References # {#normative-references}

Normative and informative references are managed via SpecRef and, where needed,
the repository-local `biblio.json`. Reference MPEG DASH normatively as
[[!MPEGDASH]] and CMAF as [[!MPEGCMAF]] once the corresponding SpecRef or local
bibliography entries are confirmed.

# Definitions # {#definitions}

: <dfn export>Addressable Resync Representation</dfn> (ARR)
:: A forward-looking concept for a Representation that enables fast tune-in and
    switching via addressable resynchronisation points. Not yet a normative
    construct in MPEG-DASH or in Low-Latency CR r8/r9, which specify
    resynchronisation via the `Resync` element; retained here as a placeholder
    pending MPEG-DASH (see `rag/reports/reconcile-low-latency-r8-r9.md`).

: <dfn export>Segment Sequence</dfn>
:: A sequence of segments as defined in the MPEG DASH baseline; usage in the
    live/low-latency context is to be reconciled with CR r8/r9 text.
